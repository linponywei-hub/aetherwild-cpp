# Starter village surface textures

Powered by Poly Haven. Source assets are CC0 1.0:

- https://polyhaven.com/a/leafy_grass
- https://polyhaven.com/a/gravel_ground_01
- https://polyhaven.com/license

`sources.json` records the original URLs, original byte counts/checksums, and shipped image checksums. Color maps retain 1024×1024 pixels and use WebP quality 87. OpenGL normal and ARM (ambient occlusion / roughness / metallic) maps are resized to 512×512 and stored as lossless WebP to bound mobile downloads. Shader inputs use sRGB for color and linear channels for normal/ARM. Assets are served locally at `/art/terrain/`.

These are material source textures, not screenshots or evidence of final game rendering.
