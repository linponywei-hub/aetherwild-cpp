# 小地圖、晝夜、陰影及武器呈現

## 行為與權威

- 小地圖取消放大整張world-atlas圖片。以同一份landscape河流／海岸、伺服器高度網格、建築、港口平台及附近角色資料繪製；生成底紋只作材質，不另造地理座標。依裝置像素比建立Canvas，北方固定朝上，玩家永遠在畫布正中央，地圖隨位置平移。未購圖的普通玩家維持原本地圖限制；管理員完整世界地圖不變。
- 新增只讀snapshot.environment={unixSeconds,cycleSeconds:1800}，來自C++系統時鐘。30分鐘是真實時間的一整日，約15分鐘晝／15分鐘夜，包含平滑晨昏；所有客戶端用同一伺服器時間並插值。日照、月光、星空、霧、環境色與小地圖時鐘跟著變化，不新增存檔欄位或影響戰鬥規則。
- WebGL預設開啟動態軟陰影，已有明確關閉設定仍尊重；地形接收陰影。Canvas相容模式提供日夜配色及低成本角色／建築接觸陰影，並非完整光線投射陰影。可在設定關閉WebGL動態陰影。
- 弓箭職業（weapon type=bow）：左鍵按住拉弓，放開射箭；1.2秒滿弓，普通射擊係數從0.55到1.6。射擊成功才扣箭及進入冷卻；取消不扣箭。弓弦、搭箭、蓄力條及釋放飛箭為呈現，命中沿用C++即時判定，尚未改成實體彈道。
- 新增bow_draw / bow_release / bow_cancel命令，沿用command request去重與相同HTTP/WS通道。C++使用world.now計時，不接受客戶端charge／drawSeconds來增加傷害；PvE/PvP共享上限。重複draw不重設時間，未拉弓放箭被拒絕，12秒未釋放視為失效，轉職／場景轉換後重拉。draw屬Motion暫態，不保存跨重啟蓄力。
- 私有snapshot.bow={drawing,charge,fullDrawSeconds:1.2}。失焦、開終端、隱藏頁面、解除滑鼠鎖定取消拉弓；前端序列化draw/release/cancel，避免延遲ACK造成孤立的蓄力。
- 匕首武器分成獨立左右手，固定畫面左右下角，隨寬高比調整並保留攻擊動作。

## 素材

內建圖像生成工具製作assets/reference/minimap-ground-v2.webp，PNG原圖保留於本次生成記錄；WebP為格式壓縮，不是把舊世界圖放大。提示詞要點：正90度俯視、無透視、低對比苔綠／橄欖草地製圖底紋、四邊連續、無文字／河流／道路／建築，實際地物由遊戲資料覆蓋。材質保持固定世界比例。
