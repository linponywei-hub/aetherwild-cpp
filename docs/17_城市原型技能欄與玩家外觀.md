# 城市原型、五格技能欄與玩家外觀

## 地圖與城市

區域中心沿用 C++ 世界資料。地圖外圈代表城市所屬領域，金色內圈代表核心建成區；領域並非全部已蓋滿街區。一般小地圖及管理員完整地圖均顯示兩種範圍，管理員資訊提供半徑與開放批次。

新增 src/modules/world/city_layout.cpp 作為擴大世界的建築與路燈碰撞來源。前端只依相同足跡製作外觀，保留舊世界幾何。城市採村落、樹城、工業城、雪城、星城、沙漠城、港城與王城等配色與建築樣式。王城包含宮殿、城牆、城門通道與塔樓。目前為低多邊形外觀原型，門窗不代表已有室內功能。

原有服務 NPC 維持服務位置，居民分散在廣場；恢復 NPC 位置時排除建築碰撞。新增建築若覆蓋舊角色存檔位置，啟動時尋找附近可站立位置，不變更財物。道路和廣場放置路燈，發光燈罩搭配至多六盞附近即時點光源，沿用晝夜環境。

## 五格技能

私人快照提供 skillSlots（固定五格）與 skillOptions（已學會、目前職業可用的主動技能）。預設選前五個符合條件的技能，未滿五招留下空格。技能面板能選配或清空每格，預設鍵位 1–5，F 使用第一格；保留既有自訂鍵位並避免新增格子佔用已綁定按鍵。

skill_slot 命令的 slot 為 0–4，skill 為技能 ID 或空字串。伺服器驗證技能所有權、職業、重複與可執行性，排除目前未實作的 dash。配置保存在既有 contentState.skillLoadout，重啟後保留，不改 Player 與資料庫格式。

## 外觀與效能

公開玩家快照僅附上實際裝備武器的名稱、類型、稀有度與強化資訊，不公開背包或私人技能。卸下武器後外觀移除。玩家與 NPC 使用 DOM 名牌，避免軟體繪圖時遺失 Sprite 文字。

建築依區塊合併幾何；景物逐格載入，每幀最多建立一格，離開後釋放。地形查詢先檢查快取邊界，小地圖限頻更新，遠端玩家採有限時間外推。軟體繪圖修正近裁切面及大型局部地形消失問題，依繪圖負載調整視距。尚未在使用者電腦量測實際 FPS，不保證所有裝置無卡頓。

## 驗證

一般與 ASan/UBSan 建置通過；核心 171、runtime 1178、content 72 項檢查（包含逐建築資料檢查）。Node 45 項測試通過。HTTP 驗證包含五格配置、非法操作、公開武器隱私與真實重啟；另有 HTTP、WebSocket、內容、雲端存取、弓箭回歸。隔離測試不使用正式角色資料。

畫面驗證使用實際 Three 幾何與軟體繪圖器，未完成正式平台瀏覽器雙玩家端到端驗證或多人壓力測試。部署狀態應以 Render 最新實際結果為準，不能將 PR 合併視為已上線。
