# GLB 世界編輯器（場景草稿）

入口：遊戲「模型編輯器」→「開啟世界編輯器」，或 `/world-editor.html`。

這是獨立的視覺場景編輯頁；不寫入玩家或正式世界資料，不改動 C++ 碰撞規則。

## 資料與操作契約

- 文件：`aetherwild-world-draft` v1。assets 保留原始 GLB bytes，objects 以 assetId 引用模型。
- 模型：穩定 UUID、名稱、position（公尺）、rotation（XYZ Euler radians）、正數 scale。
- 碰撞箱：隸屬模型的 UUID、局部 position、rotation（XYZ Euler radians）、size（長／高／深）。世界矩陣為模型矩陣乘上箱體的局部矩陣；非均勻模型縮放加箱體旋轉可能產生剪切，下游碰撞引擎必須處理或拒絕，不能直接當作軸對齊箱。
- 加入 GLB：讀取、驗證大小與格式、完整解析後才加入場景。多檔其中一檔失敗時全批不加入。原始幾何與材質不重寫。
- 匯入場景：完整驗證、載入所有模型成功後取代目前草稿；任何失敗保持原場景。可復原匯入。
- 編輯：數值須有限；座標／角度範圍絕對值 ≤ 1,000,000；縮放與箱體尺寸 ≥ 0.001。最多 200 assets、2,000 objects、每模型 100 箱。每 GLB ≤ 50 MiB，合計 ≤ 150 MiB。
- 碰撞箱：新增時包覆模型，可分別編輯局部座標、角度與三軸尺寸，亦可刪除或重新包覆；箱體會隨模型變換。
- 復原／重做：保留最近 30 次修改，不複製不可變的 GLB bytes。
- 保存：IndexedDB 的單筆原子寫入，700ms debounce；寫入失敗提供匯出提示。瀏覽器資料被清除或換裝置時不保證保留。
- 匯出：JSON 內嵌 base64 GLB，連同物件與箱體，能於其他裝置匯入。未使用的資產不匯出。

## 現階段界線

碰撞箱目前是編輯資料與預覽；沒有宣稱會阻擋遊戲角色。後續應由具 Owner 驗證的 C++ 接口讀取、驗證、儲存及發布，並同步 MovementPreview 和原生碰撞。在這之前，不提供「套用正式世界」按鈕。

GLB 支援範圍沿用專案 vendor loader；Draco、Meshopt、KTX2 等 required extensions 不支援時會報錯。並非完整 Blender 網格編輯器，無法藉調整整個模型位置直接修補網格破洞。
