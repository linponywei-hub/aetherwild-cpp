# 工作站測試路線

## 開始與操作

從已開啟的工作站選「繼續上次冒險」，或建立新角色。點擊畫面以環視；WASD移動，Shift奔跑，Space跳躍。Esc釋放滑鼠後可操作視窗；B／V開旅人終端，P設定，C聊天。

軟體投影是無WebGL工作站的相容顯示，光影與畫質較簡化；遊戲規則仍由相同C++服務執行。不要因沒有硬體繪圖而改回舊JavaScript遊戲規則。

## 1. 新手流程

1. 面向村中央公會接待艾琳，E交談。
2. 接取「旅人的第一份補給」。
3. 走出村莊，在東側X約80–92、Z約18–26，尋找可撿的樹枝／石頭；靠近E，等待進度完成。
4. 每個節點同時只能由一人採集。走離過遠或死亡不應取得物品。
5. 完成四次後回艾琳領獎，檢查經驗與金幣只增加一次。
6. 再收集樹枝3、石頭2，終端→製作→石斧。採集熟練度達12後，用斧頭砍伐資源樹取得木材。不能徒手拾取木材。

## 2. 戰鬥與副本

- 村外可見灰狼，瞄準後左鍵；Q使用武器技。法師普攻消耗MP，遊俠需要箭矢。R喝藥。
- 死亡後用「返回城鎮」，檢查回城位置、HP/MP與經驗損失。
- 風息遺跡入口位於風鈴村北方X=0、Z=-61，在破屋門前E進入。
- 清除守衛後，找到三個機關，分別靠近E；首領在前置未完成時不能受傷。
- 擊殺首領，走到後方寶箱E領取。應解鎖風息護幕技能；再按E不能重領。
- 走回入口傳送門E離開。F可施放已學技能。

## 3. 以管理工具快速驗收

第一位角色是測試Owner。B→管理→「領取測試補給」，可取得Lv.60、金幣、材料、工具與已支援的技能。此操作有明確測試用途，不能冒充正式角色進度。

- 管理→城鎮瞬移：六城都應有不同場景，NPC能互動。
- 終端→製作：劍的高階鍛造必須在燼鐵，弓在翠冠，法杖在星穹；在其他城市不應扣掉材料。
- 管理→前往副本入口：先到入口，再E進入，不是直接把副本設完成。
- 功能開關：停用採集／製作／戰鬥等後，對應操作必須由C++拒絕。

## 4. 高架城市與落下

- 星穹城樓板高度62m；北／南方向依場景Z+110有升降台與兩個呼叫站。
- 在上站而台在下站時，E先呼叫；到站後再次E搭乘。上行到站後應維持在樓板，不能掉回地面。
- 翠冠城32m，從Z+150處沿中央斜坡走到城上。
- 高架城下方應是野外地面，可以通過；不能因XZ進入城市就被拉到高樓板。
- 可從城上跳出城外；6m／0.6秒內不扣血，超出按上限計算，低血量仍可能摔死。
- 中途存檔重啟升降台，目的地與乘客狀態應保留。

## 5. 多人與隊伍

1. 在另一個瀏覽器視窗開啟同一工作站，使用建立角色，而不是繼續同一名角色。
2. 已進遊戲的視窗各自保留當次角色；互相應能看到移動與在線名單。
3. 終端→隊伍：建隊、邀請另一角色，對方接受。沒有邀請不能直接加入。
4. 隊友都在入口8m內且符合等級，隊長進入後應位於同一Run。
5. 每個隊員可領自己的通關寶箱一次；共享王裝不是人人保底。
6. Owner開PvP後，在城外攻擊非隊友應扣對方實際HP；城內與隊友之間應拒絕。

本版本沒有壓力測試或大量玩家容量承諾；不要將工作站測試身分作為正式網際網路登入方案。

## 6. 保存

用右下角「儲存進度」。重要命令本來就會保存，另有每10秒檢查點。正常重新整理選繼續，應恢復角色；重新啟動C++服務，世界、獎勵去重、隊伍、共享Run與權限也應存在。

目前檔案在runtime-data，關閉前保留資料夾即可；不要把含工作站登入映射的執行資料公開分享。交付ZIP排除執行資料，只含新專案、測試與參考素材。
