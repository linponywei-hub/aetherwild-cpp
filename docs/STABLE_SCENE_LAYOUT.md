# 房屋姿態保存與第三方場景契約

房屋 001 的既有手動設定必須優先於自動擺正。不修改原 GLB；缺少使用者數值時不得猜測或宣稱還原。

- 舊瀏覽器鍵 aw-village-glb-transforms-v1 保留相容。新姿態完整保存 group position、model position、Euler rotation/order、scale，避免只存角度卻重新計算另一個基準。完整姿態載入後不重新推算地基。
- 匯入舊／新 JSON 先全量驗證，失敗保留原設定；保留匯出與重設。本機預覽與伺服器保存分開顯示。
- Owner 才能執行 village_pose_save，五棟既有房屋範圍、有限數值、正縮放及預期 revision 由 C++ 驗證。失敗原子回復；去重與世界存檔／備份沿用原生規則。
- 伺服器姿態為公開場景外觀，不含登入資料。完整姿態優先序為本機未發布編輯、伺服器世界設定、預設。其他裝置能讀取已發布姿態；免費站重新部署的世界保存限制仍適用，不能宣稱永久雲端保存。
- 此處不擴張 GLB 碰撞發布；仍不宣稱視覺模型的任意姿態已成為原生精確碰撞。
- 世界編輯器採用 Three.js r160 官方 OrbitControls／TransformControls，保留數值欄與復原，操作器拖曳不觸發視角旋轉。
- 近景植被使用 Poly Haven CC0 草與灌木，經 glTF Transform／meshoptimizer 離線整理成普通 glTF 2.0 GLB。本地提供、固定預算、共用遊戲與編輯器；失敗維持既有可用場景。

驗收包含本機舊值載入優先、完整姿態不受基準更新影響、匯入失敗不變、Owner 權限、stale revision、指令去重與重啟保存、第三方來源／資產雜湊及幾何預算。硬體 WebGL 不可用時必須保留視覺驗收限制。

## 修正範圍與現有資料

Three.js 官方 r160 GLTFLoader／BufferGeometryUtils 已取代自製讀取器，保留原房屋 GLB 位元組。官方 TransformControls 用於遊戲內房屋與獨立世界編輯器，OrbitControls 用於獨立編輯器視角。手機編輯時隱藏遊戲移動／環視區，避免操作器拖曳同時移動角色。

伺服器保存使用全域 revision，落後的裝置必須重新讀取。正在編輯中的本機草稿不會被其他裝置的更新覆蓋。已發布的本機快取標記 serverRevision，之後可接受較新的伺服器版本；尚未發布的舊手動設定仍優先。本機寫入前保留上一份設定於 backup 鍵，匯入也先備份原設定。

目前沒有取得使用者當時房屋 001 的精確手動數值，也未搜尋到對應的 JSON 匯出檔。因此本次不能宣稱已還原那一組姿態；舊瀏覽器還保有的設定可直接沿用／匯出再匯入，不能以推測角度代替。

## 驗證紀錄

ASan/UBSan 原生 core/runtime/content 通過；content 454 checks、runtime 1,254 checks。前端 71 個測試通過，包含原房屋 001 和第三方植被的官方 GLB 解析（圖片解碼使用 stub，非 GPU 畫面驗收）、姿態矩陣重載、舊值優先、貼地與下載失敗回退。新 HTTP 測試驗證 Owner／訪客／未登入權限、revision、去重、公開場景姿態、第三方模型位元組與真正程序重啟。既有 HTTP、WebSocket 與地形格測試通過。

同一工作環境先前已回報 WebGL unavailable；此回合仍不能宣稱實際 GPU 操作、圖片解碼、材質畫面或手機幀率已驗收。原角度缺失與永久雲端保存限制亦未被隱藏。
