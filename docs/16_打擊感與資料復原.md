# 打擊感、遠端平順與資料復原

獨立分支 ai/combat-save-recovery。延續原圖與港口補丁，無付費資源變更。

## 呈現

揮擊立即回饋；伺服器Damage且actor為本人時才觸發傷害跳字、受擊閃光、音效與45ms武器停頓，移動模擬不暫停。音量預設35%，保留已設定的靜音。

羅盤依yaw計算朝向與連續標籤位移。其他玩家／怪物使用150ms位置緩衝，NPC依1秒生活更新使用1.05秒緩衝；拒絕倒序樣本，傳送重設。只是呈現延遲，不改伺服器判定。玩家公開snapshot新增可選yaw，本人private snapshot新增weaponType，未公開他人的隱藏職業。

所有職業的第一人稱武器都附到武器相機並最後繪製；材質不套用世界霧，避免被遠景壓住。Canvas保留置頂排序。

## 儲存的實際界線

目前Render免費服務仍是暫存檔案系統，未啟用持久磁碟或SQL。增加原子存檔頻率不能防止平台清除檔案。

擁有者在線時，每30秒透過唯讀API取得世界備份，保留在該瀏覽器IndexedDB。依伺服器epoch保留最近5個程序版本，避免重部署後空世界覆蓋上一版。清除網站資料、換瀏覽器或擁有者不在線時，這項暫時備援不能保證所有玩家進度；請匯出檔案並啟用真正持久儲存。

## API與資料

- GET /api/admin/backup：Bearer驗證，僅Owner；回傳format=aetherwild-world-backup、version=1、world（既有world-v2資料）。包含全部玩家與工作階段，必須私下保管，永不放入Git。
- POST /api/admin/restore：僅現有Owner或正確GAME_OWNER_CODE；body為backup、confirm=RESTORE_WORLD，可選ownerCode。大小限2MiB，普通指令仍16KiB。回傳恢復後的Owner token。
- 還原前建立私有.pre-restore檔案，驗證／保存失敗恢復舊世界；會重設運動輸入、更新傳輸epoch並重新套用布局／地形補丁。保留角色ID、金幣、倉庫、角色權限和登入映射。無SQL schema變更。
- 操作入口：B→設定→存檔與備份。角色入口的「世界備份與還原」可下載瀏覽器舊版本，輸入擁有者碼並選檔還原。還原會取代目前世界，UI有確認。

## 持久磁碟待批准方案

具體配置見deploy/persistent-storage-proposal.json：保留現有Singapore單一服務，升級Starter並掛載1GB到/app/runtime-data，預估US$7.25/月，另計超額流量、稅及未來價格變更。未執行付費升級。磁碟模式只支援單實例，部署有短暫停機。

Docker啟動時只初始化受限的存檔目錄權限，然後以UID/GID10001執行遊戲；避免新掛載磁碟無法寫入。需使用者同意費用後才實際掛載，並執行重啟保留角色／裝備／金幣驗證。

本次檢查線上已有6個角色，而現行785443b版本沒有世界匯出API，免費服務又無Shell存取；這批修改不能在未確認一次性重置或取得舊備份前直接部署。付費與重置批准互相獨立，請勿因程式已合併就自動更新Render發布分支。
