# 翠冠城與登入修正驗證

- 舊圓形地板、舊建物與碰撞、舊外部樹及臨時房屋載入路徑移除。全新外部來源見模型 README。
- 新地面由中央平台、四片分離平台、四座吊橋及 100 階木梯組成。伺服器與預測採相同平台／吊橋尺寸；四條橋路徑連續採樣檢查，島間不能踩到隱形圓地板。
- 所有模型從本站載入；InstancedMesh 合批，按距離延後載入。外部量化頂點轉浮點後再套節點矩陣，避免 Int16 溢位破壞橋面。
- /api/session 回傳帶同步序號的初始世界快照；前端可直接進入，省略原本額外的 /api/state。舊伺服器回應仍可使用備援 state 請求。
- API 逾時涵蓋回應內容解析，非僅標頭；登入前與頁面隱藏時暫停繪製。
- 本機基線量測：health 約 1ms、session 約 9ms、初次 state 約 25ms。這是本機基線，不能推論手機或 Render 的端到端耗時。線上健康端點一次約 6 秒，尚未建立手機端耗時分解。
- C++ runtime：18 組、3613 檢查通過；HTTP 35、WebSocket 29、慢連線隔離與重啟通過；雲端權限 22 檢查通過；JS 90 測試通過。
- 已檢視 Blender 組裝模型、入口與橋端；本環境 Chromium 啟動受系統 socket 限制，未完成實際瀏覽器／手機 WebGL 驗收。未宣稱登入延遲已根治或設計圖的所有建築裝飾已完成。

- 服務 NPC 與登入抵達點設於樹幹外側木平台，另檢查所有翠冠 NPC 位於有效城市地板；平台配置在前端只計算並快取一次。
