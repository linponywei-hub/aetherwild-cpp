# 工作站之後的剩餘開發

0.2.0已完成權威工作站、HTTP命令、多人快照、共享副本、JSON世界保存、基礎碰撞與第一人稱呈現。接續時從以下尚未完成的項目開始；不要再把已完成部分當空殼重寫。

## 正式帳號與發布

- 實作IAuthentication：Google OAuth、可靠的帳號與角色綁定、正式Session失效與恢復。
- 工作站第一位角色自動取得Owner，只適用獨立測試環境。正式環境必須移除此引導方法，從受信任帳號取得管理權限。
- 制定HTTPS、服務生命週期、部署、監控與多人容量目標，量測後才能承諾承載量。
- 現在的HTTP為單程序順序執行，不能冒稱跨服或分散式MMO。

## 正式持久化與原玩家匯入

- data/schema_v1.sql仍是未接線草案。實作SQLrepository、expectedRevision比對寫入、角色／獎勵／事件的同一交易，以及崩潰恢復。
- 目前world-v2.json有備份與一致檢查點，可供本機工作站重啟；不是正式多程序資料庫。
- 原ZIP沒有正式玩家資料。匯入前須取得授權匯出，先做dry-run，核對角色、物品、金幣、無法對應ID與已領獎勵，再處理正式資料。
- 不更改原站，也不自動將測試Owner或測試補給寫進正式角色。

## 完整玩法

- 進階與隱藏職業技能：召喚、連鎖、汲取、職業專屬大招、完整技能樹與全部裝備特效。
- 精確膠囊命中、弓蓄力與彈道、暴擊、PvP技能平衡。
- 完整首領技能預警與階段、怪物路徑導航、居民日程與對話。
- 不同副本獨立佈局與特殊機制、傳承獎勵、週期入口、完整故事鏈。
- 強化／修理／耐久、銀行、拍賣與玩家物品交易。
- 各城市不同商店貨架、完整地圖與探索標記、自訂按鍵重綁。

## 美術與編輯器

- 將正式GLB模型導入可視化管理，不把參考圖片當成完成的骨架角色。
- 模型上傳檢查、動作／材質、實體碰撞與資產版本映射。
- 城市／NPC路線／地形／副本編輯器，具草稿、驗證、套用、版本與回滾。
- 精細原版樓板、船體、原野地形、隱藏入口與房屋內部。
- 獨立引擎原生客戶端如有需要，再實作IRenderer與輸入介面；目前瀏覽器呈現不擁有遊戲數值權限。

## 每項功能的交付標準

1. 有明確資料模型、操作、前置條件、狀態轉移與失敗不變條件。
2. 領域邏輯放C++，畫面只發送意圖；不能把給裝備、扣HP、扣金幣放前端。
3. 檢查有效與無效路徑，包括距離、所有權、版本、冷卻、材料、重播與重啟。
4. 在工作站實際操作，再更新docs/04及VALIDATION，如實說明未測平台。
5. 保留星穹到站不回落、翠冠斜坡、城下通行、城市樓板材質與摔落上限等回歸驗收。
