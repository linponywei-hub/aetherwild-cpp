# 管理員完整世界地圖

獨立分支：ai/admin-world-map。入口：B → 管理 → 完整世界地圖。

地圖分為「目前世界」及「完整規劃圖」。後者包含25個區域與規劃道路，顯示未開放區域、開放批次、地表／地下層和座標。尚未啟用擴建時，規劃圖所有區域均標為規劃中。範圍圓與道路連線為示意，並非精確地形或道路曲線。

滑鼠滾輪以游標為中心縮放，拖曳平移，雙擊放大；亦有＋、−、全圖和關閉。點選區域顯示詳細資訊。地圖只在互動或尺寸改變時重畫，不增加常駐繪圖迴圈。

## 共用介面

- GET /api/admin/map，沿用 Authorization: Bearer session。
- WebSocket channel: admin_map，沿用既有 auth、id／_reply 配對與 _sync。
- 兩個通道共用 GameRuntime::adminMap；僅 owner/admin 可讀。未登入或一般玩家均由伺服器拒絕。
- 回應：ok、expanded、release、planned[]、current[]、roads[]。
- 區域：id、name、center{x,z}、radius、open；planned 額外含 layer、release。
- 道路：a、b（規劃區域ID）。所有資料來自現有 contentBundle／Catalog。
- 不回傳玩家、帳號或工作階段資料，不改變區域開放、傳送權限。
