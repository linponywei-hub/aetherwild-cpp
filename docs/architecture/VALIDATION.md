## 發現但未改寫的素材問題

`tests/artwork_assets.py` 未通過：50 張既有裝備 PNG 與 manifest 中記錄的 SHA-256 不一致。已逐一確認圖片與 manifest 均和基準提交完全相同，此問題在整理前就已存在。沒有為了通過測試而改寫雜湊、替換圖片或刪除素材；需要另外核對美術來源後修復。這不計入通過項目。

## 驗證界線

本輪驗證模組載入、資料投影、原生規則、網路及保存；未重新做完整硬體 WebGL／手機視覺驗收。Windows/macOS、Docker 映像未實機建置。世界編輯器碰撞箱仍是本機草稿，未新增伺服器發布功能。

CMake 首次建置產生一個零位元的中間 object，連結失敗；移除該空白編譯產物、重新編譯後，連結與 sanitizer 測試全部通過。沒有改變遊戲邏輯來繞過檢查。
