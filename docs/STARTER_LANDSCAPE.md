# 新手村近景重製契約

範圍為原風鈴村出生點、村口及周圍約 320 公尺；維持原世界地圖、區域 ID、房屋位置及玩家進度。不是全世界照片級美術完成宣告。

## 資料與不變條件

- 地形版本 3。`atlas_surface.starterVillage` 定義村莊、地圖像素、核心整平半徑、過渡距離、近景範圍及道路／廣場寬度。
- C++ 保留中心 96 公尺整平，包含出生點、原服務 NPC 與五棟房屋。外圍平滑接回原圖自然高度；其他城鎮與暗黑森林規則不變。
- 遊戲與 GLB 編輯器共用材質、道路遮罩與近景裝飾；地面高度只取原生格網。新增草與小碎石為無碰撞裝飾，不新增可採集資源或阻擋物。
- 移除新手村舊的交叉單色道路幾何，改為貼在地形材質上的道路及廣場，避免浮空與重疊。
- 實拍材質隨程式本地提供，不依賴玩家連到第三方網站。來源、授權與雜湊保存在 `assets/reference/terrain/sources.json`。貼圖未載入或載入失敗時維持程序式材質，不顯示全黑地面。
- 草與碎石以有界、固定種子的合併網格呈現，不隨每幀重建。相容 renderer 不建立密集草網格。編輯器地形格更新時重新貼地，過期請求不覆蓋新視點。

## 驗收

原生測試檢查核心區高度保持、村外起伏與連續性、地圖錨點不變、API／遊戲高度一致、舊存檔遷移後進度保留。前端測試檢查道路／房屋排除、確定性、網格預算、原生貼地與貼圖失敗回退。HTTP／權限／存檔重啟及 sanitizer 必須通過。

本環境的硬體 WebGL 若仍不可用，必須明確記錄，不能把 shader 組裝測試稱為 GPU 畫面驗收。照片級程度、手機幀率與模型細節需另以實機驗證。

## 已執行的驗證

Release 建置通過：core 181、runtime 1,254、content 444 checks。前端 63 個測試包含貼圖回退、材質與地形裁切合成、道路／房屋排除、裝飾網格預算與素材雜湊。HTTP 驗證六張本地 WebP 的實際路由、MIME 與位元組，並檢查 24 個地表區域及遊戲／編輯器高度一致。

Managed Chrome 實際開啟編輯器後回報 WebGL unavailable，故未通過硬體畫面、GPU shader 執行與手機幀率驗收。沒有產出或宣稱遊戲實景前後對照；素材預覽也不能當成遊戲截圖。此次仍未替換舊樹木與房屋，因此不能稱為整座村莊照片級完成。
