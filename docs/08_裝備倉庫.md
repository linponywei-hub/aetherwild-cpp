# 裝備倉庫與卸裝（0.2.2）

## 模型與規則

Player.inventory 為可穿戴的背包裝備；Player.warehouseItems 為該角色保管中的裝備實例。兩者 ID 不得重複，倉庫裝備不可被 equipped 引用，其他玩家不可存取。移動實例保留 ID、定義、稀有度、需求等級與強化等級，不重新生成裝備。

## 流程與操作

- unequip(target=實例ID)：活著且正穿戴該裝備時，移除穿戴參照並重新計算角色能力；裝備仍在背包。
- store_item(target=實例ID)：活著、世界場景、距離商人8公尺內；裝備必須在本人背包且未穿戴。檢查完成後移入本人裝備倉庫。
- withdraw_item(target=實例ID)：相同商人條件；僅能從本人的倉庫移回背包。
- 失敗不得改變所有權或裝備數量；指令沿用 request 去重與整體回復機制。
- 瀏覽器終端→背包：已穿戴裝備可「卸下」；未穿戴裝備可「存入倉庫」；裝備倉庫可「取出裝備」。不在商人附近由原生服務拒絕並顯示原因。

## 保存與相容

世界 JSON 增加可選 warehouseItems，舊世界缺欄位視為空倉庫。角色檔寫入 AWCHAR 2 並讀取 AWCHAR 1／2；新版有倉庫資料時不能交給舊版程式覆寫。倉庫不出現在他人的公開角色 JSON。

## 驗證與限制

測試包括穿戴／距離／他人拒絕、反覆存取保留ID與數值、重複請求、重啟恢復、舊角色檔載入、舊JSON缺欄位，以及損壞的重複ID／穿戴參照拒絕。HTTP整合測試涵蓋實際卸下、存入、重播、取出與進程重啟。前端已做語法檢查，此輪尚未以瀏覽器手動點擊驗收。

此功能不加入跨玩家共用倉庫、倉庫交易或正式帳戶系統。雲端Free方案的存檔生命週期限制仍存在。
