# 參考地圖與完整世界補丁

本次獨立分支 ai/reference-world-patch，從 main 的管理員地圖版本接續。25區依使用者1254×1254原圖像素錨點定位，64公尺／像素；王城中心為圖上(633,578)，世界(0,0)，半徑10240公尺。世界邊界±48000公尺，容納原圖80.256公里及外側緩衝。全區圖使用 assets/reference/world-atlas.webp。圖是位置與範圍基準，現有3D場景仍為程式幾何模型，不宣稱已還原原畫所有建築。

## 原生介面與存檔

- GameRuntime 正常啟動自動載入全部現有內容、開放25區，不需管理員切換世界。保留 release=5、expanded=true 作舊API相容欄位，UI不顯示批次。
- world-v2.json 的 contentState 新增 layoutVersion=2。舊未擴建或舊擴建座標依參考圖遷移，保存角色ID、登入token、背包、倉庫、金幣與劇情資料；副本中的角色不搬移。後續新增內容以程式／資料補丁更新，勿重新引入分批開放介面。
- C++ GameRuntime 可明確指定 legacyTestWorld=true 建立歷史物理與版本遷移測試fixture；正式HTTP入口不使用此選項。
- catalog 新增 atlas（圖檔、像素原點、比例、bounds及舊座標資料）和 worldLimit；admin/map沿用原owner/admin授權並新增atlas。既有input/command/state與角色欄位保持相容。
- terrainPatch改為33×33、32m網格，512m快取單元，最多64個快取；每次回應仍有地形供客戶端預測，不反覆執行2401點高度計算。
- 無SQL、部署環境變數或秘密值變更。

## 呈現與輸入

- 大世界移動預測使用伺服器地形網格與worldLimit，保留伺服器權威碰撞、跳躍與校正。以輸入序號對應本機時間重播未確認輸入，涵蓋上行與下行延遲；測試600ms回應延遲與8000m座標下的首幀移動、跳躍及持續行走無固定拖延。
- 效能面板預設隱藏，由設定開關，位置移至左下。天空球半徑改為1000m，小於相機far，避免20km天空球超過18km相機far而裁出中央白色背景；重疊角色距離小於1.1m時隱藏模型，避免鏡頭穿入頭部。場景裁切遠處城市／NPC／入口，瞄準只檢測附近可互動物件，減少網格遍歷。
- 移除全域職業進階表、委託分頁、附近隱藏入口列表、羈絆分頁與分數。NPC對話保留自然發現、符合條件的訓練與請求；不是刪除這些玩法規則。
- 新圖資料在 data/content/regions.json、atlas_layout.json；作者入口座標同步於newDungeons.json，執行generate_content.py更新原生嵌入資料。

## 終端設定補丁

終端增加固定「設定」分頁；提供音量與試聽、亮度、滑鼠靈敏度、300–8000m渲染距離及13項按鍵重新綁定／恢復預設。設定保存於目前瀏覽器的aw-* localStorage，未更改角色存檔。按鍵資料有版本與重複／保留鍵驗證；移動仍送出原本x,z,jump,sprint命令，沒有更改網路API。硬體渲染距離控制相機、霧與遠處物件裁切；Canvas相容模式另限制在350m內以避免效能暴跌。

城市地板：移除每座城市額外的210m半徑圓形貼片；地面城市使用原生高度地形，僅保留星穹／翠冠實際94m平台及與碰撞一致的橋樑／斜坡。

## 地形與港口追補

data/atlas_surface.json 定義原畫的海岸多邊形、河道、山峰與生態區，以及潮汐船城、西岸霧港、南川河口的船甲板、棧橋、上下坡。generate_atlas.py單獨生成atlas_data.cpp，避免重排大型內容包。C++ atlas_terrain.cpp 產生高度與港口可站立平台；catalog.landscape提供同一份呈現資料，客戶端地形使用頂點顏色，船城不再是一張平面貼圖。現階段是原圖位置與輪廓的幾何場景，尚不是原畫級模型與材質；海水為呈現／平面通行，沒有宣稱完成船舶航行或游泳系統。

陰影預設關閉，設定提供動態陰影開關。硬體模式的第一人稱武器移到獨立scene／camera，清除深度後最後繪製；世界物件無法再蓋在武器之上，武器本身仍有正確前後遮擋。相容模式沿用置頂排序。

港口甲板、船隊、棧橋平面尺寸按各港口原圖半徑等比展開；海上船城保留船甲板，西岸與河口中央使用碼頭岸台，區別陸港與船城。

contentState.terrainVersion=1 標記地形補丁；首次升級會重新落地並更新NPC地形錨點，之後重啟不重複遷移。
