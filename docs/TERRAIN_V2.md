# 原地圖地形 v2

## 地理與不變條件

`assets/reference/world-atlas.webp`、`data/content/atlas_layout.json` 與 `data/atlas_surface.json` 是原地圖依據。維持 64 公尺／像素、原點 (633, 578)、25 個區域錨點及原有海洋、河流、山峰、生態區、港口座標。新增 relief 參數不改寫原幾何。

C++ `atlas_terrain.cpp` 使用固定 seed 的連續多尺度噪聲、山峰包絡與山稜擾動；沙漠加入沙丘，台地加入平滑階地，海岸與河岸平滑降至水面。這不是水力侵蝕模擬。暗黑森林中心像素 (57, 694)、半徑 75 像素內為 1 ± 0.7 公尺，外圍另有 25 像素漸變。

## 資料契約

- `POST /api/terrain`，JSON `{x, z}`，沿用既有 JSON 與 `X-Aetherwild-Client: 1` 檢查。只公開地形，不含玩家、權杖或存檔。
- 座標必須是有限數字且在世界範圍 ±48,000 公尺內，否則 400。
- 回應只含 `ok`、`terrain`、`worldLimit`。terrain 含 version 2、side 65、step 16、原點 x/z、4,225 個高度；高度保留毫米。覆蓋 1,024 公尺，512 公尺對齊，最多快取 64 格。
- 遊戲 snapshot 的 `content.terrainPatch` 使用同一個原生函式。瀏覽器只建立網格與插值，不決定物理地形。
- 全圖仍採低解析遠景網格，視點附近改用高解析網格；遠景裁切保留原材質 shader。
- 編輯器有請求序號與區域跳轉序號，過期結果不覆蓋新視點。離線失敗可重試，不改模型資料。

原生移動與碰撞使用 v2 地面高度。既有 terrainVersion 遷移升至 2，調整地表角色與 NPC 的站立高度；保留原有背包、職業、等級和帳戶流程。模型碰撞箱仍為草稿，尚未發布到原生碰撞。

## 驗證與限制

原生 core/runtime/content 測試、ASan/UBSan、瀏覽器模組測試及 HTTP 傳輸／重啟檢查通過。`tests/terrain_http.py` 驗證 24 個地表區域、座標限制、唯讀與未授權資料隔離，並逐欄比對編輯器與遊戲高度格。

材質加入坡度岩石、雪地遮罩、世界座標噪聲及微表面法線。測試環境無硬體 WebGL，已檢查 shader 組裝與幾何資料，但無法在此確認實際 GPU 畫面、幀率或照片級品質。應在有 WebGL 的裝置實際檢視山區、沙漠、河岸及暗黑森林。
