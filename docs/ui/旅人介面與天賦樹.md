# 旅人介面與天賦樹整合

- 旅人資訊：雕邊徽記、職業名稱、數值生命／魔力、經驗資訊。
- 技能欄：沿用已登錄透明圖庫，強化金屬邊框、按鍵、冷卻及魔力不足狀態。
- 旅人終端：統一深色翡翠與古金配色、裝備展示、資料卡、分頁；補回任務入口。
- 天賦：36 個節點，征伐、守望、匠心各 12 個；保留原版九個 ID。連線以真實 parent 關係繪製，且提供文字前置條件。

## 規則與流程

C++ 提供 talentDefinitions、player.talents 與 talentPoints。Lv.2 起每級 1 點，每節點 1 點、只能學一次；須達需求等級、學會前置且角色存活。learn_talent 沿用既有角色綁定、請求去重、保存與失敗復原；前端只能送出節點 ID。天賦跨職業保留，未加入洗點。

利刃、生命、防禦等屬性由統一 bonuses 計算；斬殺在目標低於 30% 生命時增傷 20%；專注減職業技能／武器技冷卻 2 秒；回復精通增加兩種藥水恢復量 25%；自然饋贈每次成功採集有 25% 機率多一份；匠心領悟使製作經驗由 10 增至 15；藥劑增效使治療藥水產量多一瓶。其餘 27 個節點使用畫面所列屬性組合，不宣稱具有額外未實作機制。

世界 JSON 沿用 world-v2，增加可選 talents 欄位；舊存檔默認空集合，以既有等級補算未花點數。AWCHAR 升為 3，仍可讀 1／2；新存檔不供舊版程式向下讀取。不得把玩家 runtime-data 加入提交。

## 驗證與限制

原生核心、runtime、內容、HTTP、WebSocket 及重啟測試已執行，具體結果見本次驗證紀錄。瀏覽器預覽被環境 URL 存取政策阻擋，未做實機視覺、滑鼠操作或窄螢幕驗收；CSS 已提供窄螢幕與減少動態效果適配。未修改正式站與正式玩家資料。既有圖庫照 ID 使用，尚無專屬美術的天賦使用分支物件圖，不能宣稱新增了 36 張獨立圖片。
