# 新手村起伏、植被、圍牆、溪流與鏡頭契約

- 地圖錨點、既有房屋 GLB 與已保存手動姿態保持。C++ 定義村內土丘、廣場／路徑／五棟房屋保護地基、淺溪與短橋；遊戲與編輯器只呈現原生高度。
- 地形 v4 使用 65×65、8 公尺間距、256 公尺對齊的原生格。維持每格樣本數，增加村內輪廓解析度。前端保留有限數量原生格，避免跨格後把已知地形降回粗略高度。
- 土丘只在村內，廣場、服務區與房屋保護區保持原高度。溪流為淺水，可涉水，不新增游泳／溺水機制。橋面與河床高度由原生定義，不能用畫面假地板。
- 圍牆使用第三方實體模型，放置與尺寸由原生 catalog 提供；阻擋與牆頂支撐需 C++／移動預測一致，不封閉主要通道。
- 植被採有界實例數量，立體草叢與灌木加密並保留道路、地基、河床排除。高／低效能預算明確；載入失敗保留原可用呈現。
- 溪流採同版 Three.js 官方 Water2 流動水面。只在近處顯示反射／折射；自製程式法線不是第三方實拍圖，來源須如實記錄。相容模式顯示簡化水面。
- 鏡頭輸入只允許一根擁有操作權的觸控；不接續舊指標，取消／失焦／隱藏／編輯模式清除狀態，拒絕不合理位移。無操作時不改角度。站立預測不以近似網格覆寫原生站立高度。

驗證：原生地形與碰撞、地基不變、河床／橋、圍牆側面／頂部、遷移與重啟；前端單指／雙指／失焦／離開編輯與閒置、原生高度快取、植被數量與排除、第三方模型載入與 Water2 組裝。硬體 WebGL 若不可用，不能宣稱畫面或手機幀率驗收。

## 呈現與預算

原生快照仍為 65×65。唯讀 `/api/terrain` 加上 `detail:true` 時回傳 129×129、8m 間距、1024m 範圍的呈現格；與即時格分別快取，不反覆加入 WebSocket 快照。遊戲與編輯器使用同一原生高度。過期呈現請求不覆蓋新位置，失敗保留舊網格並稍後重試。

植被候選池加密為 9,000 個採樣位置，實際只選鄰近的最多 1,500 叢草與 40 株灌木（CPU 執行緒數 ≤ 4 時為 750／20）。草 85m、灌木 120m；移動超過 8m 才更新實例排序。掃描資產就緒後不再重建隱藏的程序草網格。

場地新增四處約 2–3.4m 的土丘、六段短圍牆及東側約 300m 的淺溪／短橋。圍牆使用 Poly Haven Modular Fort 01 真正的 thin straight wall 模組（645 triangles），非材質球或貼圖預覽。溪流為官方 Water2 + Reflector + Refractor r160；兩張法線為本專案以數學生成的 DataTexture。近處使用 256px 反射／折射，遠處與相容 renderer 使用簡化水面。沒有流體模擬或游泳宣告。

## 驗證紀錄與限制

Release core/runtime/content 通過（runtime 1,260、content 449 checks）；ASan/UBSan 三組原生測試通過。前端 81 個測試含手指所有權、噪聲／大位移／失焦、無慣性、站立高度、快取、過期呈現請求、Water2 組裝、河道及植被預算。Release HTTP／WebSocket、24 區與大型呈現格、房屋姿態、模型雜湊、存檔重啟與權限測試通過。

同一環境先前確認無 WebGL，GPU 材質／水面實際畫面、觸控手感與裝置幀率尚未實機驗收。高度與圍牆查詢改為快取數值設定，避免每次移動解析 JSON。優化後 ASan/UBSan 三組測試及嚴格 HTTP／WebSocket 計時、重啟測試全部通過；先前的 sanitizer 超時已重現並修正。
