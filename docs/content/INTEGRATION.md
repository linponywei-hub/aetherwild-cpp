# 內容整合第一階段（權威交接）

此分支把原素材包接到原生 C++20 / HTTP workstation；不是 UE 專案，也不是所有設計已完成。`design_scope.md` 是原始設計來源，實際完成範圍以本文件為準。

## 已實作

- 編譯進 C++ 的內容索引：441 怪物、1681 技能設計、46 職業、660 裝備／紀念物、263 NPC（原包238另加25服務角色）。圖鑑可搜尋名稱、背景、招式及動畫描述。
- 十種起始職業含坦克、刺客；46職業註冊、武器類型、各職業六個主動技能原型。技能所有權、消耗與傷害在伺服器判定。坦克嘲諷與護盾有實際效果。
- NPC 獨立人格資料、作息／短距移動、玩家個別好感度與記憶；聊天、實際淨購物、完成委託提升，蓄意攻擊扣分及24小時安全限制。分數、冷卻、折扣、隱藏委託及一次性贈物由伺服器保存，禁止客戶端直接指定分數。
- 25區、五批各五區，王城座標(0,0)，第二批開放。管理員明確啟用64km×64km世界；舊世界不會自動遷移。關閉區域的移動、傳送、副本與內容入口由C++阻擋，客戶端顯示邊界標記。
- 高低地形由 C++ 決定並傳送附近網格。城市與道路展開；180個副本入口定義、26個世界／選配頭目定義。關閉區域的怪物不活動。
- 75條區域故事圖以對話、實體調查桌取證、回報選擇運作；閱讀附近書籍，NPC私密委託採閱讀區域書籍與交付藥草的共同原型。
- 怪物招式共用蓄力、鎖定位置、圓／環／線／扇形伺服器範圍判定，客戶端顯示預警。存檔保存擴圖批次、羈絆、故事、紀念物及NPC位置。

## 仍是設計或原型

1681條是技能設定與動畫規格數量，並非1681套已完成的獨特戰鬥或骨架動畫。被動、召喚、衝刺、護送、水閘機關及專屬劇本需後續實作。新裝備數值、部分職業效果及新區怪物密度仍需平衡。

完整城市建築街區、地下失落城獨立場景、水域游泳、購屋、公會、寵物、坐騎、競技場與經典故事特殊場景仍待製作；資料保留供接手。地下城目前使用世界錨點，不能視為已完成地下城市。地形是通用丘陵／山地原型，不是最終美術與水文地圖。

NPC目前是每人獨立狀態的規則式AI，沒有外部語言模型呼叫。贈物與委託採共用流程，並非263套獨立劇本。傷害、消耗、範圍、開區權限不得移至瀏覽器。

## 操作與建置

`python3 tools/generate_catalog.py` 保留原目錄生成方式；修改 `data/content` 後執行 `python3 tools/generate_content.py`，將JSON嵌入 `src/content_data.cpp` 與分片，部署不需要另外讀資料檔。

`python3 tools/test_content.py` 用 g++ 建置並跑原核心、runtime及內容測試；`ASAN_OPTIONS=detect_leaks=0 python3 tools/test_content.py --sanitize` 跑ASan/UBSan。正常CMake也會包含分片及content測試。

`python3 tests/content_http.py build/aetherwild_workstation` 驗證真HTTP與重啟。所有測試只使用暫存測試世界。

管理員在故事頁啟用擴圖（`expansion_start`），再以 `content_release` 逐批開放，禁止跳批。玩家入口有圖鑑、故事與NPC羈絆；`class_attune` 在公會取得一次訓練武器。
