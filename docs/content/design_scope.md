# 給接手重製AI的實作順序

## 本次交付的邊界
這是內容庫、動畫文字規格與可執行的獨立領域參考程式。沒有替原遊戲部署功能，沒有取得正式站自訂怪物／GLB，也沒有生成1681份骨架動畫。大量技能是機制母題的不同命名與故事變奏，不應一次加入所有招式讓怪物失去可讀性。

先以原遊戲v0.30.1程式、前故事包v1與擴圖包v2.1核對。現有444刷新點、55副本、8世界王、15職業、84裝備的ID不變。新資料以aw_為前綴；原技能與角色已有紀錄採增量欄位。不要重建正式站，不覆寫玩家物品需求、強化、職業歷史、任務進度或圖片指標。

## 資料表與引用
- 00：直接從原模組載入的現有資料快照。
- 01：444個野外刷新點全部對應命名物種，原type／座標／等級仍保留。
- 02：441份怪物定義，包含125野外物種、110種副本守衛職務、180副本首領及26世界王／可選事件。
- 03、08：46職業與1681筆技能記錄；原職業技能原本是CLASS.skill欄位，新增索引不是改寫原技能解鎖ID。
- 04、07、11：套裝、全部裝備／紀念物、材料與工具。collectible是新收藏類型，不能塞進原五槽裝備面板。
- 05、06、13、14：每NPC人格、好感委託框架、個人對話提示詞與關係規則。
- 10：職業練習委託。新起始職業先選用，再提供練習，不鎖在未開放王城或高好感後。
- 12、v2_*：區域、故事、NPC、首領、職業、裝備與五次開放的連結。

原副本runtime mob id是實例中的字串索引；新guard archetype只作模板引用，不取代原mob主鍵。原有世界王5招的風險範圍、蓄力與第3階段倍率仍來自raidMoveFor，不能只看新美術提示詞就改判定。

## 職業與戰鬥必改項目
原classWeapon與classOrigin用硬編碼白名單，新職業若直接塞入會全被當成劍系／戰士。必須改成顯式職業註冊表：origin、role、weaponTypes、resourceType、parent、unlockRule；未知職業直接拒絕，不默認回落長劍。新職業不自動繼承舊隱藏職業資格。

原本只有sword/staff/bow。第一版新盾劍、雙匕首等可作單一主武器組合模板，避免默默加副手槽卻未計算套裝；若另做offhand，需要擴充裝備驗證、模型掛點、套裝件數和存檔。弓箭消耗、施法時間與原遠程規則保留；砲手與工具槍另有彈藥／熱量模型，不借用弓箭API假裝完成。

坦克需要服務端仇恨、面向格擋、耐力、護援與可嘲諷窗口；支援貢獻需計入世界王參戰與分配。刺客需可見性、破隱、背側判定與離戰規則。治療、召喚、部署物、障礙、位移均需場景／世界層／隊伍權限與清理上限。不要把對真人PvP的嘲諷做成強制轉鏡頭或接管操作。

新技能先做少量機制母題（近擊、投射、扇形、落圈、直線、環形、護持、治療），再掛不同名字與特效。每次只配3–6招到一隻王，確認預警、收招、安全區與技能排程不產生無解重疊。

## 動畫與模型
每種骨架先做idle/walk/turn/attack/cast/stagger/death。四足、巨蟹、龍、蠍、浮環、根肢與人形不得強行共用同一人形動畫。原模型設定只支援idle/walk/attack/work四個命名欄位；需增量加abilityClips映射或狀態機，不能傳入未知欄位讓validModelConfig拒絕。

時間線的resolve_effect_server是同步設計，不是讓客戶端動畫回調決定傷害。服務端公布castId、startTime、windup與落點；前端播動畫和特效，受擊後果由服務端結算。對於位移技能，播放root-motion不能越過未開放區或牆壁。死亡／斷線／換層時取消未結算施法，已結算效果以收據冪等處理。

## NPC參考程式怎麼用
執行：node --test reference_runtime/npc-engine.test.mjs。
這份程式沒有HTTP API、持久化適配器、導航、模型服務或正式商城連接。resolveReceipt必須由伺服器從已核實的購物／委託／攻擊收據讀取，不能直接return玩家請求body。角色身分驗證在呼叫前完成。

schema.sql只供本地SQLite領域驗證，不是原專案的已編號migration。接入原資料庫時用最新migration序號增量建立表，原正式站的交易／批次能力需另驗。更新關係與建立贈物outbox必須原子提交；outbox送貨也以claim_key唯一去重。原程式採NPC安全保護時，仍可新增經驗證的「蓄意攻擊企圖」事件，無需真的殺死主線NPC。

## 分期接入
1. 建怪物／技能／裝備／職業註冊表與只讀圖鑑，不動舊戰鬥。
2. 在風鈴做艾琳、米菈、鐵叔、露恩、奧里的獨立關係與規則AI，驗證多人隔離。
3. 做守衛與刺客的起始選擇、各4個可裝主動技能、訓練場和1隻世界王切片。
4. 通過模型、判定、隊伍和伺服器測試後，按v2.1每批5區開放。王城固定第2批。
5. 逐步加入新職業與NPC記憶；有需要才接模型生成對話，保留固定台詞回退。

## 整合驗收
原職業與背包完整；遠程／箭矢消耗正確；坦克與治療計參戰；玩家重登後好感不丟；一位玩家攻擊不降低別人好感；退款無套利；同張收據不重複結算；私人任務與NPC贈物不越過世界開放門禁；NPC被攻擊後公共主線服務仍可用；關場後部署物與召喚物清理；低細節遠景沒有可被提前打的首領；圖鑑數量通過不代表實機已通過。


## 區域與NPC可用性適配器
createNpcEngine必須傳入canAccessNpc，按已發布世界版本、區域門禁與當前NPC安全互動資格判斷；未開放時不加好感、不提供新任務或贈物。退款作已驗證交易的帳務回沖例外，不要求玩家能親自走到已關閉商店。原主線委託者標為critical_service，個人退避時由公共調停／服務站承接必要回報。
